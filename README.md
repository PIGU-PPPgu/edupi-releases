# EduPi Desktop Releases

这里是 EduPi 教师智能体桌面端的官方二进制发布仓库。

- macOS：Apple Silicon DMG
- Windows：x64 安装程序
- Linux：x64 Debian 包
- 自动更新：Tauri `latest.json` 与签名资产

稳定版本会显示在右侧 **Releases**。EduPi Desktop 只会安装通过永久 updater 密钥验证的完整应用更新；不会在线替换单个脚本或依赖。

源码、设计文档和开发讨论保存在私有的 EduPi Desktop 源码仓库。本仓库只公开安装包、版本说明、许可证与更新元数据，不公开教师数据或本机配置。

> 首个正式签名版本仍在发布前验证中。没有标记为正式 stable 的草稿或预览包不会触发客户端自动更新。
